# DhkBusRoute 🚌

> **Dhaka Bus Routes, Intelligent Connections & Published Fare References**  
> Fast, offline-first Progressive Web App (PWA) for Dhaka commuters.

Live Web App: **[https://tee-uwu.github.io/DhkBusRoute/](https://tee-uwu.github.io/DhkBusRoute/)**

## ✨ Features
- **Route Finder**: Search direct routes and transfer options between 180+ stops across Dhaka metro.
- **Accurate Fares**: Distance-based calculation using official government diesel bus tariff matrices (BDT 2.70/km with BDT 10 min fare) and student concession calculation.
- **Interactive Visual Route Map**: Node-by-node stop inspector showing stop names, sequences, distance from start, and total journey distance.
- **Conductor AI**: Natural language assistance powered by Gemini to guide your transit planning.
- **Progressive Web App (PWA)**: Installable on Android, iOS, Windows, and macOS with offline service worker support.
- **Bilingual**: Seamless switching between English and Bengali (বাংলা).
- **Dark / Light Theme**: Adaptive visual appearance.
- **Trip Card Sharing**: Export visual journey cards as PNG or share via Web Share API.

## 🛠️ Tech Stack
- Standalone HTML5 / CSS3 / Vanilla Modern JavaScript
- Progressive Web App (Service Worker + Web App Manifest)
- SVG Vector Visualizations & HTML5 Canvas
